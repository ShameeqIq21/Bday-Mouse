# About
This project is a mouse that was designed for my little sister. Throughout this project, I learned to masterfully extrude across multiple parts, create clean sketches with custom planes, and produce intricate designs by converting image files to SVG, then to DXF. 

# Design
The left and right sides of the mouse resemble the Lamborghini Huracan and a Ferrari F40. The back is the name of a very popular anime that my sister loves to watch - Apothecrary Diareis - and on the top is a Smiski, an action figurine.

# Why I created this 
I created this for my sister's 15th birthday. She likes cars, anime, and Smiskis. This is my form of creativity
